# CIVITA

**Computational Infrastructure for Validation, Integration, Testing, and Assessment**

### From Model Development to Predictive Engineering

CIVITA is an open, community-driven scientific platform dedicated to advancing the predictive capabilities of computational models for concrete and concrete structures through systematic calibration, validation, and benchmarking.

The initiative addresses a fundamental challenge in computational mechanics: developing sophisticated models is not sufficient to establish their predictive reliability. Computational models must be assessed against independent experimental evidence, evaluated across diverse loading conditions and material behaviors, and compared using transparent, reproducible procedures.

CIVITA aims to provide the scientific infrastructure necessary to support this transition from model development to predictive engineering.

**Website:** [civita.network](https://civita.network)

## The CIVITA Platform

CIVITA is organized around four interconnected components.

### 1. Concrete Experimental Database

An open repository of experimental data describing concrete materials, specimens, testing conditions, and measured responses.

The database supports standardized data collection, structured querying, and reuse of experimental evidence for computational model development and assessment.

### 2. Parameter Identification

Tools and standardized procedures for identifying computational model parameters from experimental data, with an emphasis on transparency, reproducibility, and consistent documentation of calibration methodologies.

### 3. Model Validation

Systematic assessment of computational model predictions against independent experimental observations, with the objective of identifying predictive capabilities, limitations, and ranges of applicability.

### 4. Computational Benchmarking

A library of standardized computational benchmarks enabling comparisons among:

- Different versions of the same computational framework.
- Different software implementations of the same computational model.
- Different computational models and their numerical implementations.

Benchmark specifications and submitted results will support reproducibility, graphical comparisons, and assessment of numerical consistency.

The four components are being developed incrementally and are intended to become interoperable through shared scientific data structures and persistent references.

## Contribute to CIVITA

CIVITA is intended to evolve through contributions from the international research and engineering community.

Researchers, software developers, and practitioners are encouraged to participate by:

- Contributing experimental datasets and computational results.
- Proposing new benchmark specifications and comparison procedures.
- Suggesting additional computational models and software implementations.
- Recommending new experimental test types, material properties, and data formats.
- Identifying improvements to existing tools, documentation, and infrastructure.

### How to Suggest an Improvement

Before opening a discussion, please check whether a similar proposal already exists.

When submitting a new proposal, we encourage you to include:

1. **Proposed improvement:** Clearly describe the requested addition or modification.
2. **Scientific or practical motivation:** Explain why the improvement would be valuable.
3. **Relevant CIVITA component:** Identify the application or infrastructure area concerned.
4. **Supporting information:** Include references, examples, technical specifications, or relevant datasets where appropriate.

Suggestions will be discussed openly and considered for future development. Proposals selected for implementation may be tracked through GitHub Issues in the relevant application repositories.

Submission of a proposal does not imply a commitment to implementation.

## Development and Scientific Principles

CIVITA is guided by the following principles:

- **Openness:** Promote broad access to scientific information and transparent assessment procedures.
- **Reproducibility:** Maintain traceable relationships among experimental data, model definitions, parameters, computational results, and assessment methodologies.
- **Model independence:** Support diverse computational approaches rather than favoring a particular model or software implementation.
- **Scientific rigor:** Distinguish between technically validated submissions and independently reviewed scientific contributions.
- **Interoperability:** Enable scientific information to be exchanged among CIVITA applications through standardized data structures.
- **Community participation:** Encourage contributions and constructive scientific discussion.

## Development Status

CIVITA is under active development. Its applications and scientific infrastructure will be introduced progressively.

The Concrete Experimental Database and Computational Benchmarking components are the initial development priorities, together with the corresponding data submission and search interfaces.

Additional capabilities, including parameter identification, model validation, and integrated scientific workflows, are planned for subsequent development.

For updates and opportunities to contribute, follow the [CIVITA GitHub organization](https://github.com/civita-network) and participate in [CIVITA Discussions](https://github.com/civita-network/civita/discussions).
